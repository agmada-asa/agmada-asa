# 👋 Hello, I’m Allen

I’m a Computer Science student at the University of Manchester, where I finished my first year with an **84% average** and received the **Netcraft Prize** as a top 10 student in a cohort of 300+.

I build AI systems, full stack products, and desktop applications. I also lead practical workshops and projects with the Manchester AI Society.

## 🛠️ Technical Skills
* **Languages**: Python, TypeScript, and Java.
* **AI & Machine Learning**: PyTorch, Transformers, RAG (LlamaIndex), Whisper, Hugging Face and Ollama.
* **Web & Cloud**: Next.js, React, Node.js, Cloudflare R2, Firebase, and Supabase.


## 📌 Featured projects

- **[NanoMath-R](https://github.com/agmada-asa/NanoMath-R)** — A 103.8M parameter recurrent Transformer built from scratch in PyTorch for mathematical reasoning. Uses 16 weight shared blocks over two passes, and ships with published weights and reproducible benchmarks.
- **[NanoMath](https://github.com/agmada-asa/NanoMath)** — A 136M parameter GPT style language model trained for algorithmic arithmetic with structured reasoning traces.
- **[TAPE](https://github.com/agmada-asa/TAPE)** — An automated podcast clip generator combining Whisper transcription with Llama 3.2 semantic analysis.
- **[Nexus](https://github.com/agmada-asa/Nexus)** — A privacy first local AI chat application using Swift, TypeScript, and RAG for offline document analysis.
- **[Mixhaus](https://mixhaus.app)** — A cross-platform audio versioning and client review workflow for music producers and engineers.
- **[Streem](https://github.com/agmada-asa/Streem)** — A full stack streaming platform with search, timed lyrics, and a custom recommendation system.
